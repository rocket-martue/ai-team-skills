# 計画：呼び名を設定で変えられるようにする（#46）

- 作成：2026-10-19 ガネーシャ
- ブランチ：`feat/46-names-config`
- イシュー：#46（Closes）

## 目的

公開したとき、使う人が自分のチームの呼び名で使えるようにする。

## 決めたこと（まーちゅう 2026-10-19）

- 文書の名前は今のまま（既定の名前）にして、`.claude/ai-team.json` の `names` に対応を書く。SessionStart のフックが、ガネーシャ（メイン）の文脈の頭に対応を入れる。メジェド・Fさんは、最初に ai-team.json を読んで読み替える
- まーちゅう（人）も対象にする
- 呼び出しの名前（`ai-team:mejed`・`ai-team:adversary`・スキル `codex`・`/code-review`）は固定。表示の名前だけ変えられる

## 変えるもの

| ファイル | 中身 |
| --- | --- |
| `plugins/ai-team/hooks/ai-team-config.mjs` | `names` キーを受ける。オブジェクトで、キーは既定の名前の6つ（ガネーシャ・メジェド・健さん・Fさん・純ちゃん・まーちゅう）だけ、値は空でない1行の文字列（改行・制御文字なし・40文字まで）。それ以外は「壊れている」（今の secretPatterns と同じ扱い。ガードは止まり、ラッパーは呼ばない）。`readConfig` の戻りに `names` を足す。あわせて、知らないキーは読み捨てる形に変える（ただし、知っているキーの打ち間違いに見えるキー（記号を除いて小文字にそろえたら同じ、か、2文字以内の違い）は、秘密情報の守りが黙って消えないよう、今までどおり「壊れている」）。この版より後にキーを足しても、古い版の PC で止まらないようにするため |
| `plugins/ai-team/hooks/session-start.mjs` | プロジェクトの `.claude/ai-team.json` を `readConfig` で読み、`names` があれば、頭の行の後に「このリポジトリの呼び名：ガネーシャ＝○○、…。以下の文書の名前は、この対応で読み替える」を足す。設定ファイルが無い・`names` が無いときは今と同じ。壊れているときは、対応を入れずに「.claude/ai-team.json を読めないので、呼び名は既定のまま」と1行足す（セッションは止めない） |
| `plugins/ai-team/agents/mejed.md`・`adversary.md` | 「最初に読むこと」に、リポジトリの `.claude/ai-team.json` に `names` があれば、その対応で名前を読み替える（自分の名前も）、を足す |
| `plugins/ai-team/skills/codex/SKILL.md` | 頼みの文の頭（「ガネーシャから」「メジェドから」）は、呼び名を変えていても既定の名前で書く（健さんの AGENTS.md がこの頭で請け負う範囲を見分けるため）、を足す |
| `plugins/ai-team/docs/team-rules.md` | 冒頭に、呼び名は `.claude/ai-team.json` の `names` で変えられ、この文書の名前は既定の名前だと1行足す |
| `README.md` | 「使い方」の下に「呼び名を変える」の節を足す。`names` を書く前に、そのリポジトリを使う全部の PC でプラグインをこの PR の後の版にし、開いているセッションを開き直す、という注意（この PR より前の版は、知らないキーの `names` を「壊れている」と扱い、全部の編集を止めるため）。`names` の書き方の例、既定の名前の一覧、呼び出しの名前は変わらないこと、キャラ設定は `docs/team/Ganesha.md`（ガネーシャ）・`plugins/ai-team/agents/mejed.md`（メジェド。プラグインの中なので、変えるならフォーク）・`<CODEX_HOME>/AGENTS.md`（健さん）にあること |
| テスト | ガード：`names` の正しい設定で今までどおり、壊れた `names`（知らない名前のキー・配列・空・改行入り・長すぎる）で止まる。知らないキー（例：`futureKey`）は読み捨てて今までどおり動き、`SecretPatterns`・`Names` のような大文字・小文字違いは止まる（今の「知らないキー（大文字小文字違い）」のテストはそのまま通る）。session-start：`names` があれば対応が入る・無ければ今と同じ・壊れていても終了コード 0 で対応を入れない・1万文字の上限。ラッパー：`names` 入りの設定で consult が通る |

コードの中の名前（コメントと、ラッパーの止めるときの文の「健さん」）は変えない。ガネーシャの文脈には対応が入っているので読み替えられる。

## 変えないもの（やらないこと）

- 呼び出しの名前（エージェントのファイル名・スキル名）
- キャラ設定の中身（口調・性格）
- `docs/tasks/` の過去の記録
- 健さんの AGENTS.md（PC ごとのファイル。名前を変える人は、そこを自分で書き換える）

## 確かめること（完了条件）

- 3つのテスト（`test-guard-code-edit.mjs`・`test-session-start.mjs`・`test-invoke-codex.mjs`）が通る。足したテストのうち、`names` の扱いのものは、直しの前の版では落ちる
- 仮のリポジトリに `names` 入りの `.claude/ai-team.json` を置いて session-start を呼ぶと、対応の行が入る（テストで確かめる）
- `claude plugin validate .`・`claude plugin validate plugins/ai-team` が通る
- 設定に `names` が無いリポジトリ（今の5つ）では、ガード・ラッパー・SessionStart の動きが今と同じ
