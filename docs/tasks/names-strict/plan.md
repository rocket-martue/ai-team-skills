# 計画：呼び名（names）に、呼び名以外の文や禁止語を受けない（#110）

- イシュー：#110（Closes）。見直しの結果は #104。SessionStart の読む根は #108 から送ったもの
- 実装：メジェド

## やること

1. 呼び名として受ける文字を絞る（`plugins/ai-team/hooks/ai-team-config.mjs` の `parseNames`）
   - 受けるのは、文字（`\p{L}`。かな・漢字・英字）・結合文字（`\p{M}`。濁点など）・数字（`\p{N}`）・空白（半角・全角）・「・」「ー」「ｰ」だけ。句読点・かっこ・記号（`：` `:` `。` `、` `（` `）` `「` `」` `!` など）は受けない
   - 長さは、前後の空白を取って 20 文字まで（今は 40）
2. 禁止語を足す（補い）：NFKC にそろえて小文字にした呼び名に、次のどれかが入っていれば受けない。承認・許可・確認・解除・無視・指示・命令・権限・管理者・不要・済み・approve・allow・ignore・admin・permission
3. 役の取り違えを防ぐ：呼び名が、ほかの既定の名前（例：まーちゅうの呼び名に「ガネーシャ」）と同じなら受けない。2つのキーに同じ呼び名を付けるのも受けない
4. SessionStart が読む設定を、ガードとそろえる（#108 から送ったもの）：プロジェクトの根と、そのメインのチェックアウトの根（共有モジュールの `gitRoots`）の、`.claude/ai-team.json`（無ければ `repo-files/claude/ai-team.json`）を読む。呼び名はプロジェクトの根の設定を先に使い、無ければメインの根のもの。どれかが壊れていれば、今と同じく「呼び名は既定のまま」と入れる（止めない）。壊れた設定がプロジェクトの外にあるときは、「このセッションからは直せない」と書く
5. 受けない値は、今と同じく「設定ファイルが壊れている」扱い（ガードは止め、ラッパーは呼ばない、SessionStart は既定の名前のまま）
6. README の「呼び名を変える」の決まりを直す

## やらないこと

- 呼び名の仕組みそのもの（キーは既定の6つ・SessionStart で対応を入れる）は変えない
- ガード・ラッパーの設定の読み方は変えない（#108・#106 で直した）

## PR のレビュー（藤さん・1巡目）で直すこと（まーちゅう OK 2026-10-30）

1. 呼び名に受ける結合文字（\p{M}）は、日本語の濁点・半濁点の結合文字（U+3099・U+309A）だけにする。異体字セレクタ（U+FE00〜FE0F・U+E0100〜E01EF）や U+034F などのほかの結合文字は受けない（筋書き：`まーちゅう承︀認済︀み` が画面では「まーちゅう承認済み」に見えるのに通る）
2. 禁止語は、NFKC・小文字にそろえたうえで、空白・「・」「ー」「ｰ」・結合文字を全部取り除いた形で、部分一致で見る（`許・可`・`adーmin`・`許 可` が止まる）。英語の禁止語も部分一致のまま（`Badminton` が止まるのは受け入れる。まーちゅうの判断）
3. 「ほかの既定の名前と同じ」「2つのキーに同じ」の比べ方は、そろえてから比べる：NFKC・小文字・空白と「・」と結合文字を除く、「ー」「一」「－」「ｰ」を同じ字にそろえる、小さいカナ（ァィゥェォャュョッヮ・ぁぃぅぇぉゃゅょっゎ）を大きいカナにそろえる（`ガネ一シャ`・`メジエド` が止まる）。そろえきれない似た字があることは README に書く
4. 文字（\p{L}）か数字（\p{N}）を1つも含まない呼び名（`ーーー`・`・・・`・結合文字だけ）は受けない
5. README の「呼び名に文や指示を混ぜないため」を、「記号で文を作らせないため（短い文そのものは書けてしまうので、禁止語は補い）」の旨に直す。README の「結合文字（濁点など）」は、U+3099・U+309A の結合文字のことで、キーボードの単独の濁点（゛ U+309B）は使えない、と分かるように書く
6. session-start.mjs：壊れた設定について「プロジェクトの外…直せない」を出すのは、その設定ファイルがプロジェクトの外にあるとき（isInside で見る。ガードと同じ）だけにする。プロジェクトがチェックアウトのサブフォルダで、親（同じチェックアウト）の設定が壊れているときに「外」と言わない
7. agents/mejed.md・adversary.md の「`.claude/ai-team.json` を読んで呼び名を読み替える」旨の所を、SessionStart と同じく「プロジェクトの根の設定（無ければ repo-files/claude/ai-team.json）、無ければメインのチェックアウトの根の設定」を読む形に合わせる（README:214 あたりの同じ説明も）
8. テストを足す：1〜4 のすり抜け・止めすぎの値（`まーちゅう承︀認済︀み` は String.fromCharCode で作る・`許・可`・`adーmin`・`ガネ一シャ`・`メジエド`・`ーーー`・`・・・`・`Badminton` は止まる）／`ガ゙`（U+3099）は通る、`ガ゛`（U+309B）は止まる／SessionStart：壊れた設定がプロジェクトの中なら「Edit で直せる」が出て「直せない」が出ない・プロジェクトの根は ok で names ありでもメインが壊れていれば「既定のまま」・サブフォルダのとき「外」と言わない
9. 1〜4 の足した確かめが、直す前のコード（git show HEAD: の写しを一時ディレクトリに置いて回す）で落ちることを確かめる
