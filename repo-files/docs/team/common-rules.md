# 共通規約

ガネーシャ・メジェドの両方が従う規約。ここを直したら、両方に反映される。

## 言語

- 会話・計画書・レビュー・コミットメッセージは日本語

## コーディング

- PHP は WordPress Coding Standards 3.0.0 以降に準拠し、phpcs.xml で定義された WordPress Custom Standard に従う
- インデント、スペース、命名規則などの WordPress コーディングスタイルを維持する
- 出力は必ずエスケープ、入力は必ずサニタイズする
- フォーム処理には nonce 検証と権限チェックを入れる
- SQL は `$wpdb->prepare()` を使う
- 翻訳関数を使い、テキストドメインを統一する
- CSS／SCSS はモバイルファースト

## 作業の進め方

- 読んでいないコードは変更しない
- 十分に調査せずに編集に飛びつかない
- 秘密情報（API キー、DB 情報、wp-config.php）は扱わない、コミットしない
- タスクの記録は `docs/tasks/<タスク名>/` に置く（plan.md、review.md）
- タスクは1本ずつ進める。別タスクの未コミットの変更が残っている作業ツリーで始めない
- 編集の制限（`.claude/hooks/guard-code-edit.mjs`）が見るのは Edit / Write などの編集ツールだけ。Bash 経由の書き込み・読み取り（リダイレクト・`sed -i`・`cat` など）は止まらない。コードの編集と秘密情報の読み取りを Bash で回り込まない（フックと settings.json の Read の禁止は、うっかりを防ぐ柵で、壁ではない）
- クライアント名・実ドメインをコード・テスト・コミットメッセージに書かない

## チーム

| メンバー | ツール | 役割 |
| --- | --- | --- |
| まーちゅう | GitHub | 要件決定、計画の承認、最終確認、マージ |
| ガネーシャ | Claude Code（メイン） | 計画書の作成、メジェドへの実装依頼、差分レビュー、頼まれたときのコミット・PR 作成、PR に付いた指摘の検証と返信 |
| メジェド | Claude Code（サブエージェント `mejed`・Sonnet） | 計画書に沿った実装、指摘の修正 |

PR に付いた指摘（Copilot・人）は、ガネーシャが検証して review.md に書く。コードの指摘はメジェドが、コード以外（`.md`）の指摘はガネーシャが直す。
スレッドへの返信と再レビューの依頼はガネーシャが行う。
